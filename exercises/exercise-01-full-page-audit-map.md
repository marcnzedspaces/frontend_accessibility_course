## Code File

Open:

[`../code/01-review-broken-page.html`](../code/01-review-broken-page.html)

## Objective

Perform a full-page accessibility audit and map each issue to the relevant course topic.

## Instructions

1. Open the page in the browser.
2. Do not inspect the code first.
3. Test using keyboard and NVDA or JAWS.
4. Navigate by headings, landmarks, links, buttons, form fields, and table navigation.
5. Record at least 10 issues.
6. Map each issue to a course topic.
7. Inspect the code only after testing the experience.

## Audit Categories

- Page structure
- Headings and landmarks
- Links and buttons
- Images and alt text
- Forms and validation
- Navigation and current page state
- Accordion/disclosure
- Dialog/modal
- Table or data display
- Chart or visual data
- Focus visibility
- Motion and visual states
- Mobile and responsive layout
- Content and semantic SEO
- Framework/component risk
