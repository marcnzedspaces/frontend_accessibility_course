# Exercise 4: Final Review Presentation

## Objective

Prepare a short final review presentation explaining accessibility findings, fixes, and recommendations.

## Presentation Length

5 to 8 minutes.

## Presentation Structure

1. Page or component reviewed
2. Top 3 accessibility issues found
3. User impact of each issue
4. Recommended fixes
5. Retest results or expected improvement
6. Framework or design-system lesson
7. Final accessibility checklist recommendation

## Required Content

- [ ] One semantic HTML issue
- [ ] One keyboard or focus issue
- [ ] One screen reader announcement issue
- [ ] One form or validation issue
- [ ] One interaction or SPA issue
- [ ] One visual, mobile, data, or content issue
- [ ] One React or Angular component consideration
- [ ] One final recommendation for the team

## Slide Outline

### Slide 1: Review Scope

```text
What page or component did you review?
```

### Slide 2: Main Issues

```text
List the top 3 issues.
```

### Slide 3: User Impact

```text
Explain how the issues affect users.
```

### Slide 4: Recommended Fixes

```text
Explain what should change in the code or design.
```

### Slide 5: Retest and Handoff

```text
Explain how to verify the fixes and what the team should remember.
```

## Reflection Questions

1. Which issue would you fix first and why?
2. How would you explain the issue to a developer?
3. How would you explain the issue to a designer?
4. What evidence would you include in a bug report?
5. What is your biggest takeaway from the course?
