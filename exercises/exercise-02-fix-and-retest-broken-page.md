## Objective

Improve the broken review page by applying the main patterns from the full course.

## Instructions

1. Choose at least 8 issues from Exercise 1.
2. Fix the issues directly in the page.
3. Retest with keyboard and NVDA or JAWS.
4. Record what changed.
5. Compare with the reference file only after your attempt.

## Required Fix Areas

- [ ] Meaningful document title
- [ ] `html lang`
- [ ] Skip link
- [ ] Semantic landmarks
- [ ] One clear `h1`
- [ ] Logical heading order
- [ ] Real links for navigation
- [ ] Real buttons for actions
- [ ] Visible focus indicators
- [ ] Connected form labels
- [ ] Help text using `aria-describedby`
- [ ] Clear error message pattern
- [ ] Semantic table with caption and headers
- [ ] Non-colour-only status
- [ ] Dialog with accessible name and focus handling
- [ ] Reduced-motion support or removal of unnecessary motion
- [ ] Mobile-friendly layout

## Retest Checklist

- [ ] Can headings be used to understand the page?
- [ ] Are landmarks useful?
- [ ] Does Tab order make sense?
- [ ] Are links and buttons announced correctly?
- [ ] Are form fields announced with names and descriptions?
- [ ] Is data understandable with screen reader table navigation?
- [ ] Is focus visible?
- [ ] Does the dialog manage focus correctly?
- [ ] Does the page still work at narrow width?
- [ ] Is the content easier to understand?
