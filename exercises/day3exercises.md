# Day 3 Student Exercises — Navigation, Overlays, and SPA Patterns

These exercises support Day 3 of the Front-End Accessibility course.

## Day 3 Theme

Accessible interactive interfaces must keep users oriented when navigation changes, panels expand, dialogs open, or routes update.

## Core Day 3 Message

The question is not only whether a component appears.

The question is whether the user remains oriented when the component changes.

## How to Use These Exercises

For each exercise:

1. Open the referenced code file.
2. Test the experience first using keyboard and NVDA or JAWS.
3. Record what is confusing, missing, or broken.
4. Inspect the code.
5. Improve the implementation.
6. Retest.
7. Discuss how the fix affected orientation, focus, state, or announcement.

## Notes

The student exercise files do not include expected answers. Reference implementations should be reviewed only after an attempt has been made.
