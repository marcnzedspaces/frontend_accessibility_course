Frontend Accessibility Foundations

Course overview

This one-day foundation introduces semantic HTML, keyboard accessibility, landmarks, headings, native controls, and light ARIA.

View frontend accessibility learning outcomes

Learning outcomes

  • Use semantic HTML for accessible page structure.
  • Differentiate between links and buttons.
  • Test basic keyboard navigation and focus order.
  • Use ARIA only when it adds useful meaning.

Course details

Day 1 topics

  • WCAG thinking for frontend developers
  • Semantic HTML and page structure
  • Landmarks, headings, and skip links
  • Native controls versus fake controls
  • ARIA-lite patterns
