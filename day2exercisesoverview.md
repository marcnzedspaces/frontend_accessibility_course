# Day 2 Exercises: Accessible Forms and Validation

These exercises support Day 2 of the Front-End Accessibility course.

## Day 2 Theme

Accessible forms are built from clear labels, helpful descriptions, logical grouping, appropriate input types, connected errors, predictable validation, and framework-safe component patterns.

## How to Use These Exercises

Complete each exercise after the trainer demonstrates the pattern.

For every exercise:

1. Open the referenced code file.
2. Test the page or component behaviour first.
3. Use keyboard navigation and NVDA or JAWS.
4. Inspect the code.
5. Identify the accessibility issue.
6. Improve the implementation.
7. Retest the improved version.
8. Discuss what changed.
