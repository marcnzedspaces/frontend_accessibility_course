# Front-End Accessibility Training Lab

This repository contains hands-on code examples, exercises, and reference implementations for a multi-day Front-End Accessibility training programme.

The course focuses on building accessible, testable, and production-ready web interfaces using semantic HTML, CSS, JavaScript, and ARIA where appropriate.

The repository is designed to support a practical learning flow:

1. Test the user experience first.
2. Inspect the frontend code.
3. Identify the accessibility issue.
4. Apply the fix.
5. Retest with keyboard and screen reader.

---

## Course Purpose

This repo is not intended to be a slide deck or theory-only reference.

It is a practical lab environment for learning how frontend implementation decisions affect accessibility, especially for users of assistive technologies such as NVDA and JAWS.

The examples demonstrate how accessibility can be improved through:

- semantic HTML
- proper headings and landmarks
- meaningful links
- native buttons and form controls
- keyboard accessibility
- visible focus states
- appropriate image alternatives
- careful use of ARIA
- screen reader testing
- progressive enhancement

---

## Repository Structure

Each training day is planned to be maintained in a separate branch.

The `main` branch acts as the general overview and entry point for the course.
