## Suggested Answer Guide

| Image Scenario | Likely Treatment |
|---|---|
| Decorative Instructor photo | Empty alt text |
| Diagram explaining page structure | Descriptive alt text or longer nearby explanation |
| Company logo linking to homepage | Alt text with company name or destination |
| Background pattern | Empty alt text |
| Screenshot showing form error | Descriptive alt text or nearby explanation |
| Icon beside visible text | Hide icon from assistive technology |
| Icon-only button | Accessible name on the button |
| Chart showing trend | Text alternative or nearby summary |

---

## Key Takeaway

Alt text should communicate the purpose or meaning of the image, not every visual detail.
