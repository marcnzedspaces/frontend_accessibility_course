## Recommended Learning Method

For each exercise:

1. Watch the Instructor demonstration.
2. Complete the exercise.
3. Test using keyboard navigation.
4. Test using NVDA or JAWS.
5. Record findings.
6. Review the code.
7. Compare with the improved version where provided.
8. Discuss what changed in the user experience.

## Day 1 Key Principle

Most accessibility improvements begin with correct HTML.

ARIA should enhance semantic HTML, not replace it.

## What's New: Practical Project Exercises

The new exercises **10–13** are hands-on projects where you will:

- **Fix real accessibility problems** in HTML/CSS/JavaScript code
- **Test with keyboard and screen readers** throughout
- **Build complete components** with proper structure
- **Compare starter and solution files** to learn best practices
- **Apply patterns** to your own projects
