ARIA-Lite Disclosure Example

Purpose

This example shows how to use a native button with aria-expanded, aria-controls, and hidden.

The button is native HTML. ARIA only communicates the expanded or collapsed state.

Example

Course details

Day 1 covers WCAG thinking, semantic HTML, landmarks, headings, native controls, skip links, and ARIA-lite.

Testing questions

  • Can the button be reached with Tab?
  • Can it be activated with Enter and Space?
  • Does the screen reader announce expanded or collapsed state?
  • Is the hidden content skipped when collapsed?
